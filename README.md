# llm-reasoning-dev
This repository contains the dev environment that is required for the llm-reasoning codebase 

Camera ready code is present in the llm-reasoning repository 

---
### Overview

This project is focused on **research and experimentation** with reasoning-capable language models.  
It provides utilities for:

- Dataset preparation and loading  
- Model training and evaluation  
- Gradient and loss monitoring  
- Visualization of training dynamics  
- Automated model pushing to a model hub  

The repository can serve as a foundation for both **academic experiments** and **prototype reasoning systems**.

---

### Repository Structure

| File / Folder | Description |
|----------------|-------------|
| `config.py` | Contains global configuration variables such as dataset paths, hyperparameters, and model settings. |
| `main.py` | Main entry point. Controls training, evaluation, and pipeline orchestration. |
| `trainer.py` | Implements training loop, optimizer, and evaluation functions. |
| `plotter.py` | Visualizes training and evaluation metrics (loss curves, gradient norms, etc.). |
| `pushtohub.py` | Handles pushing trained models or results to external model hubs or registries. |
| `test_playground.py` | Experimental sandbox for quick tests or debugging ideas. |
| `fol_sympy_nl.csv` | Dataset containing mappings between first-order logic, SymPy expressions, and natural language. |
| `fol_sympy_nl_16k.csv` | Extended version of the dataset (≈16 000 samples). |
| `Gradient_Norm.png` | Visualization of gradient norms over time. |
| `Training_Loss.png` | Visualization of loss evolution during training. |
| `raw_evaluation_loss.png` | Raw loss output from evaluation runs. |
| `requirements.txt` | Lists required dependencies and their versions. |
| `.gitignore` | Standard ignore rules for Python projects. |

### Dataset used 


Dataset used :  [`yuan-yang/MALLS-v0`](https://huggingface.co/datasets/yuan-yang/MALLS-v0)

<details>  
<summary> --------------Dataset Details-------------- </summary>
<br>
MALLS (large language Model generAted natural-Language-to-first-order-Logic pairS) consists of pairs of real-world natural language (NL) statements and the corresponding first-order logic (FOL) rules annotations. All pairs are generated by prompting GPT-4 and processed to ensure the validity of the FOL rules.

MALLS-v0 consists of the original 34K NL-FOL pairs. We validate FOL rules in terms of syntactical correctness, but we did not conduct a rigorous alignment check on the pairs, meaning the FOL rule may not accurately reflect the meaning of the NL statement.

MALLS-v0.1 consists of 28K NL-FOL pairs that are filtered from v0. We manually checked the alignment for 1K samples and developed a filtering pipeline to filter the main dataset.
</details>
